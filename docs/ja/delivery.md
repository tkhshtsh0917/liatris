# イベントの永続配送

[English](../delivery.md)

## ブラウザと受信側

コレクターの `queue` オプションに `createQueuedDelivery` のインスタンスを渡します。アプリケーションのプロファイル、そのハッシュ、`createHttpDelivery(endpoint, { requireAcknowledgement: true })` で作った送信処理を指定します。収集の前にコレクターへ同意を渡します。`queued` は IndexedDB への保存完了、HTTP 204 は受信側での永続化の完了を示します。直接送信モードは設定した配送処理が成功すると `sent` を返します。

キューには同一オリジン・テナント・アプリケーションで最大64件を保存します。配送対象の有効期限は24時間で、キューが動作した時点で期限切れの項目を削除します。満杯の場合は新規イベントを拒否します。一時的な失敗では同じイベント ID と内容で再送し、上限付きで `Retry-After` の待ち時間を反映します。恒久的に拒否された項目は削除します。トークンはリクエストごとに取得し、キューには格納しません。同意、再接続、タブの表示状態の変化で再送を再開します。

タブは IndexedDB 上の同意の世代、セッション、キューを共有します。同意を撤回すると、一つのトランザクションでセッションと送信待ちを削除し、世代を更新します。通知を受け取ったタブは進行中の送信を中止します。遅れて実行された処理が IndexedDB を更新する前にも世代を確認します。収集サービスにすでに達したリクエストは受理済みの場合があります。受理済みデータはサーバー側で削除します。

リファレンス受信側はイベントを SQLite に保存してから HTTP 204 を返します。同じ内容の再送は HTTP 204 となり、保存は一件です。同じテナント・アプリケーションとイベント ID に別の内容を送ると HTTP 409 を返します。データベースのパスは `LIATRIS_DB` で指定でき、デモの既定値は `liatris-demo.sqlite` です。本番データを保存する際は保存期間と削除の方針を決め、データベースファイルへのアクセスを制限します。

## ストリーミング先への転送契約

導入先が低遅延のストリーミング基盤を選び、サーバー側のアダプターで接続します。アダプターは送信待ちテーブルから確定済みのイベントを読み出し、UBI エンベロープと `event_id` を保ちます。転送先が受理を確認したイベントだけを転送済みにし、バッチの一部だけが失敗したときも、受理を確認できなかったイベントは再送できるように保持します。転送先ごとの上限とエラー処理はアダプターで扱います。ブラウザと受信 API の受領契約は配送先を問わず共通です。

転送先がイベントを受理してから送信待ちテーブルに反映するまでの間にプロセスが停止すると、再配送されることがあります。下流の読み取り側は収集範囲内の `event_id` で重複を排除できます。

## 接続例としての Amazon Kinesis Data Streams

一つの SQLite の送信待ちテーブルとストリームに対して、一つの転送ワーカーを動かします。`LIATRIS_KINESIS_STREAM`、`AWS_REGION` と、サーバー側の AWS 認証情報プロバイダーを設定します。ワーカーは `LIATRIS_DB` を使い、テナントとアプリケーションを選ぶ TOML プロファイルは `LIATRIS_PROFILE` で指定できます。ローカル検証で HTTP の Kinesis エンドポイントを指定した場合は HTTP/1.1 を使います。

```sh
npm run forward:kinesis
npm run test:kinesis
```

Compose のテストは、リファレンス HTTP 受信側への送信、同じイベント ID の再送、Moto から読み戻したイベントの照合まで確認します。バッチの一部だけが成功する場合は単体テストで検証します。IAM ロールは対象ストリームへの書き込みに限定し、本番の IAM ポリシーとサービスの制限は AWS 上で検証します。[Kinesis の IAM 文書](https://docs.aws.amazon.com/streams/latest/dev/controlling-access.html)

ブラウザ配送の検証は `mise run wasm` で WASM を作り、`npx playwright install chromium firefox webkit` でブラウザを入れて、`npm run test:browser` を実行します。受領応答の消失、再読み込みをまたぐ保持、別タブからの同意撤回を確認します。
